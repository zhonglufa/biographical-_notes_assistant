> **符号标准**: Crow's Foot (Peter Chen, IDEF1X)

## §3.4 ER 图

### 3.4.1 决策目标

| 问题 | 答案 |
|------|------|
| 支持什么决策 | 数据实体有哪些？实体间关系如何？主键/外键/约束？ |
| 谁读 | DBA、后端开发、数据工程师 |
| 决策后果 | 关系错了 → 数据不一致；缺实体 → 功能无法实现 |

### 3.4.2 元素完备性

| 元素 | 必须 | 说明 |
|------|------|------|
| 实体矩形 | ✅ | 每个实体一个矩形，标注名称（大驼峰） |
| 属性列表 | ✅ | 每个实体的所有字段，PK 下划线、FK 斜体、UQ 标注 |
| 主键标记 | ✅ | 下划线标注 PK |
| 外键标记 | ✅ | 斜体标注 FK |
| 关系线 | ✅ | 实体间的连线，标注关系基数 |
| 关系动词 | ✅ | 每条关系线标注动词（如"拥有"、"属于"、"生成"） |
| 基数标注 | ✅ | 1:1、1:N、N:M，使用 Crow's Foot 符号 |
| 图例 | ✅ | 符号含义 |

### 3.4.3 Crow's Foot 符号规范

| 符号 | 含义 | SVG 实现 |
|------|------|----------|
| `||` | 恰好一个（1） | 两条竖线 |
| `^<` | 多个（N） | 三叉戟（Crow's Foot） |
| `o|` | 零或一个（0..1） | 圆 + 竖线 |
| `o<` | 零或多个（0..N） | 圆 + 三叉戟 |
| `—` | 必选一个 | 单横线 |

### 3.4.4 线条与间距

| 参数 | 标准值 | 说明 |
|------|--------|------|
| 实体矩形间距 | 40px（最小） | 两个实体之间的最小距离 |
| 实体矩形尺寸 | 宽 180px × 高 自适应 | 宽度固定，高度按字段数动态 |
| 字段行间距 | 6px | 同一实体中字段行的垂直间距 |
| 字段左缩进 | 12px | 字段文字距实体左边框 |
| 关系线间距 | ≥ 14px | 多条关系线平行时保持间距 |
| 关系线与实体间距 | 12px | 线与实体边框的距离 |
| 关系动词偏移 | 线中点上方 4px | 不压线 |

### 3.4.5 颜色与字体

| 元素 | 色值 | 字号 | 字重 |
|------|------|------|------|
| 实体头部 | `#1A73E8`（蓝） | 13px | Bold |
| 实体头部文字 | `#FFFFFF`（白） | 13px | Bold |
| 普通字段 | `#333333`（深灰） | 11px | Regular |
| PK 字段 | `#1A73E8`（蓝） | 11px | Bold（下划线） |
| FK 字段 | `#DC2626`（红） | 11px | Regular（斜体） |
| 关系动词 | `#666666`（中灰） | 11px | Regular |
| 基数标注 | `#333333` | 10px | Bold |
| 字段类型 | `#666666` | 10px | Regular |

### 3.4.6 审查清单

```
□ 4.1  决策目标：ER 图覆盖了哪些业务域的数据模型？
□ 4.2  实体完备性：所有实体是否与文档实体列表一一对应？
□ 4.3  主键：每个实体是否有 PK 标记？
□ 4.4  外键：关系对应的外键是否在字段列表中斜体标记？
□ 4.5  关系基数：每条关系线是否标注了 Crow's Foot 基数？
□ 4.6  关系动词：每条关系线是否有动词标注？
□ 4.7  关系交叉：是否有任何两条关系线交叉？
□ 4.8  线条规范：实体间距 ≥ 40px？关系线间距 ≥ 14px？
□ 4.9  颜色系统：PK 蓝色、FK 红色、普通字段深灰？
□ 4.10 复杂度：实体 ≤ 15？关系 ≤ 20？字段 ≤ 20？
□ 4.11 元数据：是否完整？
□ 4.12 可追溯：实体/关系/字段是否对应 PRD？
□ 4.13 跨图一致：实体列表/表结构/时序图操作是否一致？
□ 4.14 图例：是否包含 Crow's Foot 符号/颜色/线型含义？
□ 4.15 生命周期状态：是否正确？
```

### 3.4.7 反模式

| 反模式 | 错误表现 | 正确做法 |
|--------|----------|----------|
| 缺少实体 | 文档有 13 个实体，ER 图只有 11 个 | 必须与文档完全一致 |
| 多余实体 | ER 图有，文档没有，时序图也没有操作 | 删除或补全文档 |
| 关系无动词 | 线只画了，没有"拥有"/"属于"等动词 | 必须标注动词 |
| 基数缺失 | 1:N 关系没标 N 端 | 必须标注两端基数 |
| PK/FK 不标记 | 所有字段一样样式，看不出主外键 | PK 下划线，FK 斜体 |
| 关系交叉 | 多条关系线交叉 | 重新布局消除交叉 |
| 实体过多 | 一张图 20+ 个实体 | 按限界上下文拆分 |
| 字段列表不完整 | 实体只画了名称，没有字段列表 | 必须列出所有字段 |
