# PRD 验收标准可测试性审计

> 审计对象：`PRD-简历自动投递与面试模拟-最终版.md`
> 审计范围：§11 验收标准表格（13 行）+ §15–§35 各需求章节内嵌「验收标准：」条目
> 审计方法：逐条判定 **A 可自动化测试 / B 需人工·观测验证 / C 需改写才能测**
> 审计产出：可直接当「测试规划输入」使用的结构化清单（待办清单式）

---

## 1. 总览

### 计数口径说明
- **验收标准块**：共 **119** 块。其中 §11 为一张含 13 行的表格（计 1 块、13 条），其余 §15–§35 各章内嵌「验收标准：」条目 **118** 条。
- **原子断言**：将含「①②③」或多项并列的验收标准拆到最小可测单元，共 **226** 条（其中 1 条 §25.3b 同时归属 C 类与待回填，见 §6）。下文 A/B/C 均以原子断言为粒度，便于直接派发测试用例。
- **待回填项**：含 `[阈值]` / 待 v0.9 实测回填 / 未定值者单列，不计入 A/B/C 但计入分母（视为「未就绪」）。

### 三类计数与占比（分母 = 226 原子断言）

| 类别 | 条数 | 占比 | 含义 |
|------|------|------|------|
| **A 可自动化测试** | 119 | 52.7% | 有明确断言点，可写单测/集成/契约/E2E 自动判定 |
| **B 需人工/观测验证** | 76 | 33.6% | 需人工检查、演练、或上线后看监控/报表判定 |
| **C 需改写才能测** | 28 | 12.4% | 当前为否定式/定性措辞，须改写为可量化/可断言 |
| **待回填（未定值）** | 3 | 1.3% | 阈值未填，回填前无法判定通过 |

> 注：待回填 3 条中 T1（§25.3b）与 C28 同指一条，已去重计；T2（§34.2①）、T3（§34.3①+②）为纯缺阈值项。C 类障碍是「措辞否定」，待回填障碍是「缺数值」，分列更易追踪。

### 一句话结论
当前 PRD 的「需求命中率」**无法在未经改写前直接量化**：仅 52.7% 的原子断言可立即自动化；33.6% 依赖演练/巡检/监控证据（B 类需建立证据采集机制才能算数）；12.4% 是「不…/清晰/可控」类否定式或定性措辞（C 类），不改写为正向可断言语句就无法写测试；另有 3 条阈值未定。障碍集中在 **C 类否定式措辞** 与 **B 类缺乏证据采集规范**。建议：先把 28 条 C 类改写为 A/B 后回写 PRD，再对 76 条 B 类建立演练/巡检记录模板，命中率方可落地。

## 5. 「需求命中率」度量方案

### 公式
```
需求命中率 = 通过验收测试的需求数 / PRD 总需求数（分母 = 226 原子断言）
```

### 分母构成与采集方式
| 来源 | 条数 | 计入分母 | 采集方式 |
|------|------|---------|---------|
| A 类（119） | 119 | ✅ 直接计 | 自动化测试套件（单测/集成/契约/E2E/CI 门禁/指标巡检）通过即计 |
| B 类（76） | 76 | ✅ 凭证据计 | 演练记录 / 巡检报告 / 法务签字 / 监控报表 / 文档评审 —— 需建立「证据采集模板」，每条 B 有对应证据项，证据齐备且达标即计 |
| C 类（28） | 28 | ⚠️ 改写后计 | 改写回写 PRD 后按 A/B 方式计；改写前不计（视为未就绪） |
| 待回填（3） | 3 | ⚠️ 回填后计 | 阈值填入 PRD 后按 A 方式计；回填前不计 |

### 分子与「通过」判定
- **A 通过**：对应自动化用例在目标环境（含真实 DAU 灰度）绿；指标类需连续观测窗口（建议 ≥7 天）达标。
- **B 通过**：证据模板齐全 + 评审/演练结论为「达成」。建议引入「B 类证据看板」，每条 B 关联：证据类型、采集时间、负责人、达标结论。
- **C 通过**：改写后的正向断言用例通过（改写后即 A/B）。
- **待回填通过**：阈值回填且对应断言通过。

### 采集落地建议
1. 为每条 A 在测试管理工具建用例，CI 出报告自动汇总通过率。
2. 为每条 B 建「证据卡」（Notion/看板），演练/评审产生即上传，季度对齐。
3. C 类先完成 PRD 回写（见 §7），再转 A/B 进入上述流程。
4. 待回填项设「发布门禁」：v1.0 发布前必须关闭（填值或明确 defer）。

### 当前可达成的命中率（乐观口径）
- 仅 A 即时可计：119/226 ≈ **52.7%**
- A + 已改写 C（28）→ 147/226 ≈ **65.0%**（假设 C 全部回写并测过）
- A + C + B 证据齐备 + 待回填关闭 → 226/226 = **100%**（理想态，需 B 证据机制与回填闭环支撑）
