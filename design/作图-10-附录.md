### 附录 B：通用检查清单（68 项）

#### 通用（12 项）

```
□ G01  图标题：是否清晰标注了图号 + 图名？
□ G02  决策目标：能否一句话说清这张图支持什么决策？
□ G03  C4 层级：是否遵守了单一抽象层级？
□ G04  图例：是否完整，所有颜色/线型/箭头/符号都有解释？
□ G05  元数据：是否包含作者/日期/版本/来源/审查状态/受众？
□ G06  生命周期状态：DRAFT/REVIEW/APPROVED/DEPRECATED 标记是否正确？
□ G07  颜色合规：所有颜色来自色板，无非色板颜色？
□ G08  对比度：所有文字与背景对比度 ≥ 4.5:1？
□ G09  字体规范：字号/字重/对齐符合层级规范？
□ G10  复杂度上限：元素数/连接数未超标？
□ G11  跨图一致：名称/接口/实体/参与者与其他图一致？
□ G12  可追溯：随机选 3 个元素，能否追溯到 PRD 或 ADR？
```

#### 线条（8 项）

```
□ L01  线宽：普通线 1.5px，强调线 2.5px？
□ L02  平行线间距：所有平行线间距 ≥ 14px？
□ L03  线与元素间距：线端与元素边框间距 ≥ 12px？
□ L04  标签偏移：标签在线上方 4px，不压线？
□ L05  正交路由：所有路径横平竖直，无斜线？
□ L06  线交叉：零容忍？
□ L07  箭头大小：统一，宽 8px × 高 6px？
□ L08  虚线间距：统一，实段 6px + 空段 4px？
```

#### 文字间距（8 项）

```
□ T01  文字重叠：所有文字包围盒无重叠？零容忍？
□ T02  文字与元素边框间距 ≥ 10px？
□ T03  相邻文字水平间距 ≥ 12px？
□ T04  相邻文字垂直间距 ≥ 6px？
□ T05  标签与线间距 ≥ 2px？
□ T06  图例与主图元素间距 ≥ 20px？
□ T07  多行文字行间距 = 字号 × 0.8？
□ T08  防重叠预处理已执行？
```

#### 颜色（4 项）

```
□ C01  色板合规：所有颜色来自色板？
□ C02  语义唯一：一个颜色在全文档中只有一种语义？
□ C03  对比度：文字/背景对比度 ≥ 4.5:1？
□ C04  色盲安全：红绿不作为唯一区分手段？
```

#### 布局与信息密度（8 项）

```
□ D01  元素比例：各元素面积是否与信息量成正比？
□ D02  空间分配：主图区 ≥ 60%，图例 ≤ 10%，留白 ≥ 15%？
□ D03  标注格式：动态信息标注是否使用紧凑格式（≤ 50 字符）？
□ D04  编号引用：超过 3 个维度时是否改用编号引用？
□ D05  拆分必要：是否满足拆分条件？如满足，是否已拆分？
□ D06  拆分关联：拆分后的图是否标注了关联图？
□ D07  图幅选择：viewBox 尺寸是否与内容量匹配？
□ D08  宽高比：是否在 3:2 ~ 4:3 之间？
```

#### 信息展示合规（8 项）

```
□ I01  图类型匹配：连接线标注信息类型是否符合 C4/UML 标准？
□ I02  C1 协议禁止：C1 中是否没有协议信息？
□ I03  C2 协议强制：C2 中每条线是否标注了协议？
□ I04  动态信息位置：动态信息是否在正确的图类型中表达？
□ I05  must/may/must not 合规：信息展示符合 §2.9 清单？
□ I06  决策流程已执行：是否已过 §2.10 决策流程？
□ I07  红线规则：是否没有违反 §2.11 红线规则？
□ I08  布局预检已执行：是否已过 §2.13 预检清单？
```

#### 版本与变更（4 项）

```
□ V01  版本号：图中版本号与文档版本号一致？
□ V02  修改记录：每次修改后更新 "最后修改" 日期？
□ V03  废弃标记：旧版本的图是否标记为 DEPRECATED？
□ V04  源文件：SVG 源文件是否保留，与图同目录？
```

### 附录 C：反模式大全（20 条）

```
AP01 万能图：一张图试图表达所有信息 → 谁也看不懂
AP02 装饰图：图很漂亮但没有决策价值 → 浪费评审时间
AP03 断层图：C1→C2→C3 跳跃太大 → 缺中间层
AP04 僵尸图：文档修改后图没更新 → 误导读者
AP05 自解释图：图没有文字说明 → 不同人理解不同
AP06 完美图：过度追求视觉完美 → 过犹不及
AP07 孤岛图：图与图之间没有引用关系 → 无法导航
AP08 无源图：图的内容来源不明 → 无法验证
AP09 幸福路径：只画正常流程，没有异常路径 → 线上故障
AP10 内部暴露：C1 中出现内部容器 → 违反 C4 纪律
AP11 用户幻觉：画了非系统用户的角色 → 误导
AP12 技术栈缺失：容器没有标注技术栈 → 无法落地
AP13 无协议线：连接线没有协议和端口 → 无法部署
AP14 激活条满格：整条 lifeline 画满激活条 → 看不出同步/异步
AP15 无返回消息：时序图有请求没有返回 → 交互不完整
AP16 无限循环：loop 片段没有标注循环次数 → 无限执行
AP17 实体缺失：ER 图与文档实体列表不一致 → 数据模型不完整
AP18 关系无动词：ER 图关系线没有动词 → 语义不明
AP19 容器当节点：部署图画成 C2 容器图 → 缺少物理拓扑
AP20 无风险标记：设计图没有任何风险/债务标记 → 自欺欺人
```

### 附录 D：自动化检查脚本接口规范

SVG 图应支持以下自动化检查，检查脚本输出格式为 JSON。

```json
{
  "diagram": "fig-c2-container.svg",
  "checks": [
    { "id": "line-width", "passed": true, "value": "1.5px" },
    { "id": "parallel-spacing", "passed": true, "min_gap": "16px" },
    { "id": "color-palette", "passed": true, "violations": [] },
    { "id": "font-size", "passed": false, "violations": ["text@y=120: 10px"] },
    { "id": "element-count", "passed": true, "count": 8 },
    { "id": "metadata-exists", "passed": true },
    { "id": "line-crossing", "passed": true, "crossings": 0 }
  ],
  "verdict": "PASS_WITH_WARNINGS"
}
```

**检查通过标准**：
- `PASS`：所有检查通过
- `PASS_WITH_WARNINGS`：仅 P2 级别未通过
- `FAIL`：存在 P0/P1 级别未通过 → 禁止合入
