## 关键设计原则 (从修复中提取)

### 1. 业务层 → 外部灰盒的统一路由模式
```
源组件 (x_s, y=340) → 垂直 60-80px → 水平到 (x_ch, y_h) → 垂直到 (x_ch, y_target) → 水平 60px 进灰盒
                ↑                   ↑                          ↑                          ↑
            起点 y=340        拐点 x=760-780            拐点 y=目标 y                   终点 x=820
            (业务层底外)      (目标容器外)              (灰盒入口 y)                (灰盒左边界)
```

### 2. 业务层 → 数据访问层的跨列路由模式
```
源组件 (x_s, y=340) → 垂直 40px → 水平到 (x_t, 380) → 垂直 40px 进数据层
                ↑                   ↑                   ↑
            起点 y=340          层间间隙 y=380       终点 y=420
            (业务层下边界)     (340~420 间隙内)     (数据层上边界)
```

### 3. 通道规划
- **y=380 通道**: 业务层 (270~340) 与数据层 (420~490) 之间的间隙
- **x=760-820 通道**: 目标容器 (右边界 750) 与灰盒 (左边界 820) 之间的 70px 通道
- **y=400 通道**: 业务层下方到底部边界 (490) 之间的间隙
- **y=555 通道**: 数据层 (490 底) 到目标容器 (700 底) 之间的中部间隙
