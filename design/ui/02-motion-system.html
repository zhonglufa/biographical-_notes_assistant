动效系统 · Motion System

为「简投 AI 助手」定义的统一动效规范。原则：克制、有目的、可关闭。本文件是动效 token 与示例的唯一来源，01-app-shell.html 复用同一套 token。

U 阶段 · 动效规范

1. 设计原则

① 目的优先，不装饰。 动画只服务于两件事：强化产品招牌交互「半自动确认闸门」（让人确认投递的那一下有踏实反馈），以及让导航/状态/反馈更跟手。不用弹跳、闪光、视差等花哨动效。

② 短而利落。 主交互 ≤ 320ms，收尾用减速缓动（ease-out），给人"即时但顺滑"的感觉。

③ 可关闭。 全程尊重系统「减弱动态效果」(prefers-reduced-motion)；开启后所有动画降级为瞬时切换，功能不受影响。

2. 动效 Token

类别Token值用途
时长--d-fast140ms按压反馈、悬停
时长--d-base200ms导航过渡、Toast、覆盖层
时长--d-slow320ms确认勾选绘制
时长--d-slower480ms卡片收起
缓动--e-outcubic-bezier(0.16,1,0.3,1)主推：收尾减速
缓动--e-stdcubic-bezier(0.4,0,0.2,1)标准进出/循环
