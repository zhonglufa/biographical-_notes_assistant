## 阅读路径

**首次阅读**:
1. 先读 [作图-01-通用规范.md](./作图-01-通用规范.md) 了解全局规则 (颜色/字体/线条/间距)
2. 再读要画的图类型对应文件 (例如 C2 容器图 → 作图-03)

**评审时**:
1. 打开 `figures/lint-svg.cjs` 跑自动化校验
2. 对照目标图类型的"审查清单"章节逐项检查

**新增图类型时**:
1. 参考 [作图-10-附录.md](./作图-10-附录.md) 的"图类型清单"
2. 仿照现有图类型章节结构编写

## v1.7 更新日志 (2026-08-15) — ST-15 灰盒左右二分与最近原则

### 新增规则
- **ST-15**: 灰盒左右二分 + 最近原则 → 通用规范 §2.4.8.1 (索引) + C3 文档 §3.9.5.1 (详细定义)
  - 3 条核心: 职能分组 / 左右二分 / 最近对齐 (≤ 160px)
  - 2 条禁止: 4 灰盒分散 3 区 / 同 y 高度 ≥ 3 条水平线

### 触发背景
- `fig-c3-component.svg` v3.0 → v4.0 重构(原 4 灰盒分散到 3 个区 + y=380 水平通道 4 线竞争)
- 重构后: 灰盒严格左右二分,所有业务层→灰盒连线 ≤ 120px 单段
- 几何检查 19/19,lint 9/9 双验证通过

### 跨文档同步
- `作图-11-C3组件图.md` §3.9.5.1: ST-15 详细定义 + 布局模板 + 反例/正例
- `作图-11-C3组件图.md` §3.9.9: 审查清单新增 3.9.16~3.9.18 三条
- `作图-11-C3组件图.md` §3.9.10: 反模式表新增 3 条
- `作图-03-C2容器图.md` §3.2.4.1: **ST-15 为什么不适用于 C2**(防止误用)
- `作图-03-C2容器图.md` §3.2.7: 审查清单新增 2.16 (ST-15 边界检查)
- `作图-03-C2容器图.md` §3.2.8: 反模式表新增"硬套 ST-15"
- `作图-01-通用规范.md` §2.4.8.1: ST-15 索引 + v1.7 更新日志

### 重要澄清
- **C3 组件图**: 必须遵循 ST-15
- **C2 容器图**: 维持 3 层 × N 列布局,**不应用 ST-15**(C2 灰盒含义不同 + 3 列独立技术栈语义不可丢)
- **思想可借鉴**: 最近原则(避免长线绕行)对 C2 同样有效,但实现方式是"总线 + 干线"而非"左右二分"

## 命名约定

- 文件命名: `作图-NN-<类型名>.md`,NN 为两位序号
- 图类型章节内: `§x.y.z` 编号
- ST 规则: `ST-N` 全局统一编号 (1~14)
- Q 审查项: `Q-N` 或 `Q-N.M` 全局统一编号

## 维护指南

1. **修改现有图类型**: 直接编辑对应 `作图-NN-xxx.md`
2. **新增图类型**:
   - 在 README 索引中添加链接
   - 创建新文件 `作图-NN-<新类型>.md`
   - 遵循通用规范 + 该图类型 UML/C4/方法论标准
3. **修改 ST 规则**: 必须同步修改 `lint-svg.cjs` 中的对应检查项
4. **修改色板/字号**: 必须同步修改 `lint-svg.cjs` 中的强制值
