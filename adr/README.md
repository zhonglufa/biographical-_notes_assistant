# 架构决策记录（ADR）— 简历智投系统

> 本目录持久化记录本项目所有关键设计决策，包含：决策内容、决策理由、候选方案对比、竞品参考依据、影响范围。
> 后期开发团队可直接"蒸馏"这些记录：每个 ADR 对应一个可执行的设计约束，开发时按 ADR 编号引用即可。

## 使用说明

- **ADR 命名规范**：`ADR-XXX-简短标题.md`（XXX 为递增编号）
- **状态定义**：`已采纳`（最终决策）/ `候选`（提出未定）/ `已否决`（评估后放弃）
- **每个 ADR 必须包含**：背景 → 决策 → 理由 → 候选方案 → 竞品参考 → 影响与约束
- **新增决策时**：先查已有 ADR 是否覆盖，避免重复；编号递增，不修改历史记录内容，只追加
