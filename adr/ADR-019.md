# ADR-019 产品视觉语言

## 状态

已采纳

## 背景

产品需要一套统一、有辨识度的视觉设计语言，以提升产品品质感与用户信任度。2026 年的设计趋势与 2022-2024 年已有明显差异，需要选择符合当前审美趋势且能体现产品科技感的设计风格。

## 决策

采用**暗色玻璃拟态 + 霓虹强调色 + Bento 网格布局 + 大号粗体排版**的视觉语言体系：

- **暗色背景**：以深色（#0a0a0f、#1a1a2e）为主色调，降低长时间使用的视觉疲劳。
- **玻璃拟态**：使用 `backdrop-filter: blur()` 实现毛玻璃效果，卡片与面板半透明叠加，增强层次感。
- **霓虹强调色**：三色体系——青色（#00f5d4，主色调）、靛蓝（#6366f1，辅助色）、紫罗兰（#9b5de5，强调色）。
- **Bento 网格布局**：参考 Bento 设计风格，信息卡片以不规则网格排列，视觉丰富且有节奏感。
- **大号粗体排版**：标题使用大号粗体字（如 48px/700 weight），与正文形成强烈对比，引导视线。

## 理由

1. **2026 年设计趋势**：Awwwards 2026 年 8 月 SOTD（Site of the Day）获奖站点如 Vero New-York（★7.21）、Thomas Carré、/nk.studio 均采用暗色 + 玻璃拟态 + 霓虹强调色，证明该风格为当前设计趋势主流。
2. **暗色模式降低视觉疲劳**：用户每天可能长时间使用产品浏览岗位与编辑简历，暗色模式可有效减轻眼部疲劳。
3. **玻璃拟态提升层次感**：半透明叠加效果让界面层次丰富、有科技感，与产品"AI 驱动"的定位一致。
4. **差异化竞争**：多数招聘类产品采用浅色模式（BOSS 直聘、智联），暗色玻璃拟态可作为差异化视觉记忆点。

## 候选方案

1. **浅色 Material Design 风格**：优点是阅读舒适度高、信息密度大；缺点是缺乏差异化，与多数竞品视觉趋同，无法体现产品科技感。
2. **纯 Bootstrap 风格**：优点是开发效率高、组件丰富；缺点是设计水平有限，无法满足产品品质感要求，且缺乏品牌辨识度。

## 竞品参考

Awwwards 2026 年 8 月 SOTD 获奖站点（Vero New-York ★7.21、Thomas Carré、/nk.studio）的设计趋势；Muz.Li 2026 Dashboard Collection 用户分享的作品。本项目视觉语言直接参考以上设计趋势。



## 补充说明：AI 面试交互设计

2026-08-13 更新：AI 面试改为**一问一答逻辑**，AI 作为面试官提问 → 用户作答 → AI 基于回答继续追问。具体交互：

- **开场面板**：用户选择岗位（Java后端/前端/算法）、难度（易/中/难）、时长（15/30/45分钟）后开始面试。
- **5 轮面试流程**：介绍→项目深挖→技术考察→HR提问→结束，顶部进度可视化。
- **关键词追问**：AI 根据用户回答中的关键词（如"MySQL"→索引优化，"Redis"→缓存一致性）触发针对性追问。
- **非"AI 自动回复追问"**：自动回复的设计错误，AI 应扮演面试官而非用户本人。

## 对开发的影响

1. 设计系统必须先在 HTML/CSS 原型中定义完整的设计 Token（颜色、字体、间距、圆角、阴影），再转化为前端框架的样式变量。
2. 暗色模式需确保文本对比度满足 WCAG AA 标准（最小对比度 4.5:1），避免可读性问题。
3. 玻璃拟态效果需考虑性能：`backdrop-filter: blur()` 在低端移动设备上可能卡顿，需做降级处理（无 blur 的纯色背景）。
4. Bento 网格布局需使用 CSS Grid 实现，确保响应式适配，禁止使用绝对定位。
5. 霓虹强调色仅用于关键交互元素（按钮、链接、状态指示器），不可大面积使用，避免视觉疲劳。
