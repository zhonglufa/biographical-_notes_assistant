# ADR-021 法律合规

## 状态

暂缓

## 背景

产品涉及以下法律合规风险，需要提前评估与应对：

1. **用户隐私数据**：收集用户简历包含姓名、手机号、教育经历、工作经历等个人敏感信息，涉及《个人信息保护法》（PIPL）的合规要求。
2. **自动化投递**：系统自动在招聘平台以用户身份投递简历，涉及招聘平台用户协议与《网络安全法》的相关规定。
3. **爬虫数据采集**：采集企业官网与微信公众号的岗位数据，涉及著作权与数据权益问题。

本 ADR 在 MVP 阶段暂不执行，但需在正式上线前完成合规工作。

## 决策

上线前需完成以下工作（建议咨询专业律师）：

1. **用户协议**：明确用户权利义务、免责条款、争议解决方式。
2. **隐私政策**：明确数据收集范围、使用目的、存储期限、用户权利（删除/更正/导出）。
3. **免责声明**：明确自动化投递的风险由用户自行承担，平台仅提供工具。
4. **数据删除流程**：用户注销账号时，自动删除全部个人数据（简历、投递记录、面试录音），并提供数据导出接口。
5. **自动化投递合规**：在半自动确认制的基础上，用户协议中明确告知自动化投递行为，并获取用户明确授权。

## 理由

1. **法律风险是最大风险**：如果因隐私泄露或违规操作被起诉，产品可能直接终止，所有投入归零。
2. **MVP 阶段先做功能验证**：法律合规工作在不了解产品实际运营数据前很难做到位，先做 MVP 验证核心价值，上线前再完善合规。
3. **半自动确认制降低风险**：用户主动确认提交的机制已经在操作层面降低了自动化投递的法律风险。

## 候选方案

（法律合规为必要事项，不存在替代方案；仅时间节点可以调整。本方案选择"上线前集中完成"而非"开发前先完成"，以加速 MVP 验证。）

## 对开发的影响

1. 用户注册时需勾选同意用户协议与隐私政策，且协议文本需以链接形式展示，同意记录需留存。
2. 系统需实现完整的数据导出与删除流程：用户发起请求 → 系统在 15 个工作日内完成数据导出/删除 → 发送确认邮件通知用户。
3. 自动化投递功能需在用户首次使用时弹出单独的风险告知与授权确认，不能仅包含在用户协议中。
4. 所有数据采集模块需记录数据来源与采集时间，为后续合规审计提供依据。
5. 用户协议与隐私政策需以版本号管理，每次更新后需用户重新确认同意。
