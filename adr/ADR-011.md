# ADR-011 文件存储方案

## 状态

已采纳

## 背景

产品需要存储多类文件：用户上传的简历 PDF、个人头像、面试录音文件、以及系统生成的报告与截图。文件存储需要兼顾本地开发测试的便利性与生产环境的稳定性，同时确保国内访问速度快、成本可控。

## 决策

采用**双环境存储方案**：

- **生产环境**：阿里云 OSS（对象存储服务），用于存储全部用户文件与系统文件。
- **本地开发环境**：MinIO（开源对象存储），用于开发与测试阶段的文件存储。

## 理由

1. **阿里云 OSS 国内访问快**：OSS 在全国部署了 CDN 加速节点，文件上传下载延迟低，适合国内用户群体。
2. **成本可控**：OSS 按量付费，前期无固定成本，存储费用低（约 0.12 元/GB/月），适合独立开发者。
3. **MinIO 与 S3 兼容**：MinIO 实现了 S3 标准 API，本地开发环境使用 MinIO 可以做到与生产环境 OSS 的 SDK 完全一致，切换环境只需改 endpoint 配置。
4. **阿里云生态完善**：OSS 与阿里云 CDN、图片处理、视频转码等增值服务无缝集成，为后续扩展预留空间。

## 候选方案

1. **七牛云 Kodo**：优点是价格略低；缺点是生态弱于阿里云，与阿里云其他服务的集成需要额外适配，且国内企业级市场占有率较低。
2. **AWS S3**：优点是全球领先的对象存储服务、功能最全；缺点是国内访问速度慢，需额外配置加速，且境外服务在国内的合规与支付存在不便。

## 竞品参考

多数国内 SaaS 产品（包括简历类、招聘类产品）首选阿里云 OSS 作为文件存储服务，实践验证成熟。

## 对开发的影响

1. 所有文件上传下载必须通过后端代理签名 URL 实现，前端不直接持有 OSS AccessKey，确保安全性。
2. 文件上传后必须返回统一的文件 ID 供业务表引用，数据库中不存储原始 OSS 路径，便于后续迁移。
3. 本地开发环境必须安装 MinIO 并配置自动启动，确保文件相关功能在本地可完整测试。
4. 敏感文件（如用户简历 PDF）的 OSS 访问 URL 需设置过期时间，禁止生成永久可访问的公开链接。
5. 图片等静态资源存储需开启 OSS 图片处理服务，支持按需缩放（如头像缩略图），减少前端带宽占用。
