# ADR-023 简历编辑器重构：WYSIWYG PDF 实时预览 + 滤镜式模板切换

## 状态

已采纳（优先级高于 ADR-022 中的"模板选择栏"部分；AI 生成部分仍沿用 ADR-022）

## 背景

用户反馈原简历编辑器体验不佳，明确要求：

1. **PDF 版本的结果可视化操作和修改**：编辑时看到的是最终 PDF 效果，且可直接在 PDF 上进行编辑（所见即所得 WYSIWYG）。
2. **模板不是"选模板"模式**：原模式是横滑卡片选模板，缩略图是抽象色块，看不到真实内容效果。用户要求类"滤镜"模式——内容不变，模板即点即换。
3. 竞品分析后确认需要**重新设计**简历编辑页面。

## 决策

采用**三栏工作台布局**重构简历编辑页面：

```
┌─────────────┬───────────────────────────┬─────────────┐
│ 左栏        │ 中栏                      │ 右栏        │
│ 模块管理     │ PDF 实时预览（WYSIWYG）    │ 模板滤镜     │
│ · 6 模块    │ · A4 白纸，1:1 效果        │ · 3 分类 6 款 │
│ · 拖拽排序   │ · 内容块点击直接编辑        │ · 色彩主题 6 色│
│ · ✦ AI 生成 │ · 缩放 75/100/150% + 全屏  │ · ATS 评分   │
│             │ · 实时反映模板/主题切换      │ · AI 建议采纳 │
└─────────────┴───────────────────────────┴─────────────┘
```

核心交互约束：

1. **WYSIWYG 编辑**：中栏 PDF 页面上的每个内容块（姓名/联系方式/经历/项目/技能/自我评价）`contenteditable` 可点击直接编辑，浮动工具栏保存/取消，Esc 可取消。编辑时实时联动 ATS 评分与建议。
2. **滤镜式模板切换**：右栏模板以真实内容缩略图展示（A4 按 0.2368 缩放），内容不变、只换版式。模板分为 3 类：精英名企 / 现代通用 / 创意设计，每类 2 款，共 6 款（corporate/elegant/modern/minimal/creative/dynamic）。
3. **色彩主题独立于模板**：6 色主题（霓虹青/经典蓝/科技紫/清新绿/温暖橙/高级灰）是一层独立"滤镜"，叠加在任何模板之上。
4. **左栏模块管理中栏定位**：点击模块 → 中栏 PDF 平滑滚动到对应区块并高亮闪烁。
5. **AI 生成入口**：左栏每个模块旁的 ✦ 按钮打开右侧滑出面板，生成内容自动定位到对应 PDF 区块。
6. **导出**：右栏顶部提供导出 PDF / Word / HTML 按钮。
7. **响应式**：≤1200px 两栏（模块横排），≤900px 单栏堆叠，PDF 预览限高 70vh。

## 理由

1. **参考知页简历**：模板切换如"滤镜"——内容不动版式变，缩略图即真实渲染效果，这是国内简历产品最成熟的交互范式。
2. **参考 Magic Resume / CareerBldr**：三栏布局（左模块/中编辑/右预览）已验证；本方案进一步把"编辑"与"预览"合一为中栏 WYSIWYG PDF，编辑即所见。
3. **参考 Enhancv**：WYSIWYG 画布直接拖拽操作，用户对最终 PDF 效果有完全掌控感，降低"填表→导出后发现排版乱"的焦虑。
4. **PDF 可视化是求职刚需**：简历最终形态是 PDF，用户在编辑期看到最终效果能显著降低返工率与投诉。
5. **滤镜式模板降低决策成本**：内容不变的前提下切换模板是零成本试错，鼓励用户多尝试、提升付费模板转化。

## 候选方案

1. **表单式编辑 + 模板预览**（原方案）：左表单右预览分离，模板缩略图为抽象色块。缺点：看不到真实内容效果，编辑与预览割裂，被用户否决。
2. **纯 WYSIWYG 画布（Enhancv 式）**：完全自由拖拽。缺点：实现成本高（拖拽/光标/区块引擎），对多数用户过重，模板约束弱。
3. **三栏 + WYSIWYG PDF（本方案）**：模块化约束 + PDF 直编，兼顾易用性与实现成本，为最终选择。

## 竞品参考

- **知页简历**：模板如滤镜，即点即换、缩略图真实渲染。
- **Magic Resume**：三栏布局，左模块管理/中编辑/右实时预览。
- **CareerBldr**：WYSIWYG 画布 + 实时 PDF 预览。
- **Enhancv**：所见即所得画布，直接操作最终效果。
- **Zety**：表单编辑 + 侧栏预览精简版。

## 对开发的影响

1. 简历渲染必须为**结构化数据驱动**：内容（JSON）与样式（模板/主题）分离，模板切换只改样式不改数据。
2. PDF 预览前端可采用 `html2pdf` / `Puppeteer`（服务端渲染）双通道：编辑期前端实时预览，导出时服务端保真渲染。
3. 模板用 CSS modifier 类实现（`mod-corporate`/`mod-elegant` 等），新模板只需新增 modifier，不侵入内容结构。
4. contenteditable 注意：保存时通过 `innerText` 取回纯文本；切换模板/主题前必须先退出编辑态（保存快照），否则样式变化会破坏光标。
5. 左栏模块顺序 = 简历 JSON 渲染顺序，拖拽排序需持久化到 `resume.template.layout` 字段。
6. 主题色通过 CSS 变量 `--accent` 注入，模板、技能标签、分隔线统一取色，禁止硬编码颜色。
7. 原型中 ATS 评分与建议为演示数据，真实实现由 Python AI 服务评估后返回。
8. ADR-022 中"横滑模板卡片选择栏"的交互描述作废，以本 ADR 的"滤镜式"为准；其余 AI 生成逻辑不变。
